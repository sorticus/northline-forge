# Invoke protocol

## New title

```text
Pull github.com/sorticus/northline-forge
Copy AGENTS.project.md to the project root.
Copy skills/pop-games into the project skill path.
Copy kit/ into src/forge/.
BEFORE any gameplay code: follow docs/18-research.md.
Web-search at least 2 comparable shipped games (how they feel, camera, controls, juice, HUD).
Fill kit/research.ts ResearchBrief. briefGaps() must be [].
Write src/forge/research.brief.json. Steal feel, never IP.
Then wire mountSessionChrome + kit/engines.
Follow FORGE standing orders. Cheap path is a ship blocker.
Then build: [GENRE] that feels like [REFERENCE GAME]. Setting: [ONE LINE].
```

## Once-over (prebuilt)

```text
Pull github.com/sorticus/northline-forge and follow FORGE.
Do NOT scaffold a new game.
Name 1–2 feel comparables, then registerAudit + runAudit().
Patch in place. Report verdict, worst 3, next patch.
```
