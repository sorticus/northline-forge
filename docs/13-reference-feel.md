# Reference feel — steal this, never the IP

Name **one** when you start a title. “Make it nice” is how rectangles happen.

We copy **timing, camera, juice, audio layering**. We do not copy characters, logos, music, UI chrome, or level layouts.

| Name it | What you are actually stealing |
|---|---|
| Celeste | Dash freeze-frames, land squash, hair/trail, coyote+buffer, death-fast retry |
| Hollow Knight | Nail hitstop, pogo, shade dash, room camera clamps |
| Dead Cells | Weapon swap weight, enemy pop, scroll speed |
| Enter the Gungeon | Reload as verb, kick, bullet readability, shopkeeper cadence |
| Hades | Attack arc, god-vfx layering, boon pickup pop (not the art style unless asked) |
| Mario Kart 8 | Drift spark → boost, chase cam, rubber-band, item panic |
| Mini Motorways | Soft camera, place-punch, muted-to-loud traffic juice |
| Crossy Road | Hop squash, voxel read, death slapstick, retry instant |
| Alto’s Odyssey | Land as the game, scarf, wind, breathing camera |
| Smash Hit | Glass burst, camera lunge, music sync |
| Monument Valley | Perspective snap, **quiet** juice, tap-to-rotate satisfaction. Never Ida, crow, those levels, that UI, that score. Recipe: `recipes/perspective-puzzle.md`. Loud FORGE trauma is wrong here. |
| Superliminal | Forced perspective as a verb (scale by camera). Don’t copy their levels. |
| Vampire Survivors | Pickup vacuum, level-up punch, readable chaos |
| Stardew | Tool/pickup juice, day sting — not the farm IP |
| Canabalt | Leap, rumble, buildings as rhythm |
| Super Meat Boy | Tight jump, gore burst, instant retry (tone down gore if needed) |
| Hades / Cult of the Lamb | Run recap, door choose, cult/meta is **not** v1 unless asked |

If the reference is 3D and you ship Canvas 2D, you ignored the engine table.

Illegal: shipping Mario, a Nestlé HUD, a photographed real firearm as a viewmodel, a trace of a copyrighted character sheet, or a Monument Valley / Ida remake.
